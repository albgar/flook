## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/`. See `.claude/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles using default strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `.claude/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `.claude/agents/domain.md`.
